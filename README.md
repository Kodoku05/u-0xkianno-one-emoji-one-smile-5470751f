One emoji, one smile: 😁, a big beaming grin with smiling eyes. The smiling
eyes are the genuine-warmth cue — a real Duchenne smile — warmer at first
glance than the plain 🙂 or 😊 defaults, and still instantly readable by any
age or background, with no irony and nothing that could land wrong from a
stranger. A smile is the safest warm signal someone unknown can send: no
intimacy, no flirtation, no hug-from-a-stranger oddness. It was chosen, not
defaulted to — the warmest first-glance smile, picked for the moment.

## Run it

```sh
node main.ts
```

Writes the emoji to `/output/entry.txt` (exactly 4 bytes, no trailing
newline). Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
